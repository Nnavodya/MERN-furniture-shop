#  MERN Furniture Store 

A full-stack e-commerce platform for furniture shopping.

## Tech Stack
- Frontend: React.js, Redux Toolkit, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Payment: Stripe
- Image: Cloudinary
